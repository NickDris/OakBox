# OakBox Documentation

## Project

OakBox is a web application built with an AI-assisted development pipeline.

## How This Project Works

Features are implemented through a 6-agent pipeline:

1. **Architect** designs the technical approach
2. **Planner** breaks it into atomic tasks
3. **Coder** implements the tasks
4. **Tester** verifies acceptance criteria
5. **Memory** records knowledge for future use
6. **Docs** writes this documentation

See `CLAUDE.md` for the full workflow specification.
